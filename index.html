Политика конфиденциальности «Школиас»

Редакция от 1 ноября 2026 года. Android-приложение, версия 1.1.1.

Кирилл Герасименко. По вопросам работы приложения и обработки данных: schoolias@bk.ru.

Какие сведения использует приложение

Школиас — автономная командная игра по школьным темам. Названия команд, настройки, текущая партия и результаты раундов хранятся на устройстве, чтобы продолжать игру и показывать результат. Настоящие имена учеников, учётные записи и контакты не требуются. Для игры можно использовать условные названия команд.

Сбор и передача данных

Приложение не передаёт эти сведения разработчику или третьим лицам, не содержит рекламы, аналитики, регистрации и встроенных покупок. Android-приложение не имеет разрешения на доступ к интернету, контактам, микрофону, камере или геолокации.

Сохранение результатов и внешние сервисы

По команде пользователя приложение создаёт JSON-файл с названиями команд и результатами. Пользователь выбирает место сохранения в системном диалоге Android. Если выбрать облачное хранилище, файл передаётся сервису, выбранному пользователем, по правилам этого сервиса. Разработчик не получает копию файла.

Ссылки на образовательные программы и политику открываются внешним браузером, а email — почтовым приложением. Сайты и приложения обрабатывают данные по собственным правилам.

Страница политики

Эта страница размещена на GitHub Pages. При её открытии GitHub регистрирует IP-адрес посетителя для обеспечения безопасности сервиса согласно политике конфиденциальности GitHub. Страница не содержит аналитики, рекламных скриптов или форм ввода.

Срок хранения и удаление

Текущая партия хранится до её замены новой партией или удаления данных. Настройки остаются до очистки данных. Удалить данные можно через Настройки Android → Приложения → Школиас → Хранилище → Очистить данные либо удалив приложение. Экспортированные файлы удаляются пользователем отдельно из выбранного хранилища. У разработчика нет серверной копии данных игры.

Использование детьми

Приложение подходит для повторения школьного материала, не требует личных данных учеников и не содержит публичного чата. Названия команд и результаты не публикуются приложением.

Изменения политики

При изменении способов обработки данных обновлённая политика будет размещена по этому адресу и в приложении. Для обращения к разработчику используйте контакт выше.
